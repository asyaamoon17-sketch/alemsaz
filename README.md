# ÁlemSaz

ÁlemSaz is a mobile-first web app concept for learning Kazakh national instruments.

## MVP included
- Russian / Kazakh / English interface selector
- Dombra / Qobyz / Shankobyz selector
- Course map and lessons
- Interactive lesson modal with tablature mockup
- Kyui quiz
- Encyclopedia
- Profile, XP, streak and badges
- Responsive mobile-first Neo-Nomad visual style

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy
Push this repository to GitHub and import it into Vercel.
